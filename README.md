# 🌾 Agriculture Production Insights Dashboard | Power BI

## 📌 Project Overview

This project analyzes agricultural production data using Microsoft Power BI to uncover trends in crop production, environmental factors, and farming efficiency across different regions.

The dashboard transforms raw agricultural data into interactive business insights that help identify production patterns, optimize resource utilization, and support data-driven agricultural decision-making.

---

## 🎯 Business Problem

Agricultural organizations often struggle to understand how environmental conditions, fertilizer usage, and farming practices influence crop production.

This dashboard helps answer questions such as:

- Which crops generate the highest production?
- Which regions contribute the most?
- How do rainfall and temperature affect yield?
- Does fertilizer usage improve production?
- Which crops experience the highest pest incidents?
- What production trends are observed over the years?

- Yield Efficiency Comparison

---

## 📈 Key Insights

- Rice and Wheat contribute significantly to overall agricultural production.
- Yield varies considerably across regions due to environmental conditions.
- Fertilizer usage generally shows a positive relationship with crop yield.
- Higher pest incidents negatively impact production efficiency.
- Rainfall and temperature are major influencing factors for agricultural output.
